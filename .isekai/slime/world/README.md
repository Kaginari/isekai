# slime-world

- **Rank:** Slime
- **Territory:** `world/`
- **Reports to:** orc-world
- **Minds:** slime-go-proving, gate-safety, slime-wire-and-journals
- **Purpose:** the ground truth of the world package — law and prompt (root discovery, lexicon, law loader, roster, territory, system prompt, log, dimension), the gate (the Orc's checks, pairing, the breaker), courts and council (dispatch, budgets, salvage, strain, relief, the ledger shelf) and ranks and ascension (the rank table, ASL, metrics, minting).

## Traits
- Law and prompt: lexicon.json holds both vocabularies (isekai, agent-one). Open validates the rank table, replays the ledger shelf, loads the law (the crest section is always in the prompt, the `law` tool loads any other section by title), and when `<worldDir>/dimension.yaml` exists parses it (LoadDimension) and runs GitSelfInit — a bare `git init` on `main` only when root is in no work tree: no commit, no .gitignore, nested repos untouched. Prompt order: crest, the race page `law/race/<rank>.md`, identity, rules in force, the creature card (+ the rank's job, layer-mates, divine rules), self-state, @ONTO (800 tokens), instructions, the memory line.
- Roster and territory: creaturesOf reads ranks off the rank dir (a doc's Rank line may name an ascended rank on that dir) and skips a doc carrying the `- **Retired:** true` mark; a creature whose one hop up is a retired seat reports to that seat's live heir (onto.HeirOf: the seat's `Heir` line, or the body whose `Ascendant of` line names it). ZoneOfPath (zoneofpath.go) is the one ownership reading — harness soil (shared/, instruments/, attic/: nobody's, never billed), scratch (tmp/: every body's nest, lawful to write, never a doc debt; a plan deck under tmp/plans speaks for its own body only, gate and Policy alike), a creature's seat (its dir, or a foreign body's doc: the seat's even under a broader claim, and Vitality never asks a doc for seat files), then the authoring creature with the longest matching territory, then a gate holder; Owner is its creature, and `onto owner` answers it too (onto.CLIOwner). Self-heal (selfheal.go): the docs are the store, the roster their cache — Reload stamps the rank dirs' seats and .md files (docStamp), and SelfHeal re-derives when the stamp moved, asked by the dispatch preflight, Engine, a held body's Policy and a roster miss; a heal never moves verifyBase, a never-seen body's lines included (only Reload does). Policy refuses every body's write under instruments/loop and instruments/usage (engine soil), and the throne's write on a creature's soil unless it is that creature's README or a throne seat file (dimension.yaml, the law).
- The gate (gate.go): Gate runs right author, doc truthful, traits hold, tests intact, UI, duties done and the injected checks. Traits hold runs the verify lines as they stood BEFORE the turn (GateOptions.VerifyBefore, else verifyBase: the lines as the last Reload read them): a line removed this turn still runs, a line added this turn is a hole and runs from the next turn. Commands run under the sandbox via `bash -c` in the root, 120 s default, exit 124 on timeout, 160-char tail. Genesis (gate_genesis.go genesisExempt): Right-author passes a zone-parent writing its own child's README while four conditions hold — the path is the child's README on its seat, the child reports to the writer (the throne: a child of rimuru), the doc is absent from HEAD (no git: the child is not on verifyBase, the roster the last explicit Reload read — a heal between the write and the gate never adds it) — one commit window — and every claim stands on the live tree, on the writer's line's soil or open ground, never covering or under a third body's (mintClaimsLiveTree).
- Pairing: a creature's doc is paired when it rides this turn's writes (arm 1), when the court-write ledger attributes it to a court and it has drifted off its clean git baseline (arm 2, docDriftedFromBaseline), or when it passed the gate in an earlier wave (arm 3, a pair mark the gate spends once). The throne re-authoring a drifted creature doc with no pairing fails right author. EndGate's breaker adds a directive after gateBreakerAt (3) identical fails on one file set for one body; a pass resets it.
- Courts (court.go): a Court is minted only for a roster name — MayOrder(from, body, opt) is the same preflight for a caller with no engine (the wake, before it claims a held order); preflight (the dispatch tool's Preflight and the Dispatcher's first act) refuses a ghost before anything spawns, naming its near miss (nearMiss: the one roster name within two edits) and the lawful targets (stratTargets); mayDispatch: work goes down the ranks (an ascended rank commands its base's children) or sideways for a Sideways rank, one rung at a time under strictFlow, and only to a creature whose Reports-to chain reaches the dispatcher unless OpenLineage — the chain is the living one (lineage: a retired hop resolves through its heir, a hop nothing living holds ends the line and is named as the break, never as the one who commissions), and a lineage refusal names the lawful route verified hop by hop against the law (routeTo: commission the nearest creature of the target's line the dispatcher may order, else carry it up with @? to where the lines meet and down; a refused hop or a broken line says so and sends it to the human); the list of lawful targets (stratTargets) is mayOrder — the dispatch law and the coded verdict, exactly what preflight accepts — over a locked copy of the roster, each body once; a rank that commands no one (Ranks.Commands) gets no dispatch tool; a gate holder may not dispatch an authoring creature whose doc, read fresh off disk, has no coded Verify. The child's step and minute budgets are the parent's remainder; the Court runs on the wire with the commission's cap; reports over 600 bytes are filed under instruments/loop and ride as an envelope. A clock death names lane and budget, records a stress death and, with salvageTokens ≥ 0, resumes one capped turn to land @U (and its drafts). forge.go: the dispatcher files r.Report.Forges (or a prose answer's @FORGE lines) with FileForges before the cap or the envelope folds them — one notes.jsonl line tagged forge with by, run and hash; a hash already filed is skipped (first filer wins, under forgeMu); the throne's DONE answer files through Hooks.Answer; FileForgeMark appends forge-minted/forge-rejected marks; the Record beat no longer re-parses @FORGE; court_vita.go's laneLadder only advises the next lane.
- Council (councilLedger, relief.go): a Court that did not land adds strain; at law.stress.escalateAt a warrant (@INSTRUCT / @SPLIT / @ESCALATE) rides the report; past maxConsults it becomes @S ESCALATE; a clean landing clears it. At relieveAt, relieve splits a zone of ≥ 2 prefixes into `<name>-a` / `<name>-b`, splits a one-prefix zone by the tree under it, or else retires the doc — and cascades: the retiree's marker names its heir (`- **Heir:**` — the first young, or its own one hop up), each child's Reports-to line is re-seated (cascadeReSeat: onto the young whose half holds its claims, or the retiree's one hop up; a doc with no such line gains one), and every doc the act wrote is filed as the court's gated writes so the dispatcher's gate leaves them alone. ledger.go appends every strain, consult, clear, death, relief and court write to shared/ledgers.jsonl and Open replays it (court writes bound to 8 per creature).
- Evolution (evolve.go, evolve_arms.go — law.evolution): after a Court's report folds (and at the run-start sweep) a body that StressOf reads stressed (strain ≥ StressAt, its last FailStreak gated runs failed, or a doom checkpoint) and whose desks (its doc's + its worn minds' under the root, DeskOf) hold more than ThoughtsMax, out of cooldown (CooldownOf: its runs after its latest `evolution` value row) and with no open proposal, evolves by one arm in the order split (author/gate family, large by the survey, Thoughts and failed paths in ≥2 zone entries) → rebirth (red own verify at its last verdict, or named soil gone) → mutate (families of shared terms; a how family minted as `<body>-<term>`). An EvolvePlan is file writes with their expected Before; applyPlan refuses a moved file, stages under tmp/evolution/<id>, runs Verify lines through w.run, proves the ontology over a symlink overlay (no new finding, every planned body on its planned soil), then swaps (undone on a write error), clears strain, notes the value row (and `rebirth`), logs, announces; a failure is a hole (logged, noted, cooldown starts). Propose mode saves the plan under evolution/<id>.json for ApplyProposal/RejectProposal. The court seam files the swapped paths as the court's gated writes and skips relief when the body evolved.
- Ranks and ascension: DefaultRanks is the law's table (elf, orc, slime, kijin, high_elf, high_orc, dark_elf); Ranks.Validate refuses a cycle, an unknown parent, an authoring rank with no gate above, and ascendsWhen/divineRules on a rank with no base. ASL (rank_eval.go) is `ascend <base> when <expr>` over reports, passes, fails, holes, passRate, failRate, holeRate, intelligence; rates are zero with no reports. Ascended ranks have their own dir and prefix; the defaults ascend on `reports >= 20 && passRate >= 90% && holeRate <= 10%`. FoldMetrics appends each report to instruments/ascension.jsonl (replayed at Open) and mints at most one ascension per body ever: the base's doc carried whole into the ascended dir under its short name, the base retired, an entry appended to log.md, a roster reload; a failed mint is a hole, logged and rendered as `@?` on the dispatcher's report.
- log.go: Entry renders `### [RFC3339] author — title` then Task, Files, Gate, Result, Learned; Log.Append refuses when the bytes it last saw shrank or changed (Law 4).
- One body, one live court: Dispatcher seats the court (World.seat, body → engine) and Close gives the seat up; a second dispatch onto a live seat is refused naming the run there. A report is filed as <run>.report.md beside <run>.jsonl. A court that dies by its clock is named by courtDeathShape from its own Result: no act = provider hang, acts but no write = recon loop, else burn (turns · acts · writes).
- A cancelled gate judges nothing (gate.go): run spawns no reading once the context has ended, and Gate then answers `cancelled` (never `fail`) with the hole "the turn's writes stand unjudged"; EndGate logs `gate cancelled` with result "interrupted — the gate did not judge", the breaker streak and the value ledger's gate note do not move, and the hook returns an error so the turn does not close done.
- The shared shelf (shared.go): `<worldDir>/shared/` (SharedDir) holds the world's shared bookkeeping: the work queue (QueuePath `shared/queue.jsonl`), the ledger shelf (`shared/ledgers.jsonl`) and the value ledger (value.Shelf `shared/value.jsonl`). Open's migrateShelf renames each instruments/ file (movedShelves) onto it once, only when the shared file is absent (a failed move is a Note); shelfReadPaths reads both homes and mergeHomes interleaves their rows by time (each file's own order kept), so a world an older binary wrote again loses nothing and a newer row in the old file is not undone by an older one on the shelf; a seed counts once — a later seed in another home (an older binary re-seeding after the move) is dropped with the rows it carried; writes go to the shared file only, and a ledger still on the old shelf is never re-seeded. Queue opens it under the rank law — Outranks: rimuru over everything (work held by no one is the throne's), else any creature up the holder's lineOf chain; a sibling or a child is not. It is harness soil: Policy refuses every body's write under it (naming the shared shelf and the queue tool) — a write tool's Paths and a shell command's Targets alike, as for engine soil — the loop never stamps it, evolve's mirror skips it. Every rank's shelf (AllTools, baseTools) carries the `queue` tool and the `fold` tool.
- One write book per world: Open makes a loop.Receipts and Engine hands the same one to every engine it builds, so the tree watch of a dispatcher leaves a background court's tool-reported writes to that court's gate (loop/snapshot.go).
- shelf/ (world/shelf): Append is the one appender of the harness's line files — the queue's commit, ledgerNote, value.Append: under the dir's flock (`<dir>/.lock`, every process), Check first, then one O_APPEND write of the line and its newline (a leading newline in that same write when the file's last byte is not one), then the seal `<file>.seal` — size, mtime and the running SHA-256 state of every byte the harness wrote (no rehash). Check: seal and stat equal → nothing (lock-free); a file with no seal is adopted as it stands; else the sealed prefix is hashed — intact: a touch reseals, bytes past it go to `attic/<file>` under a `# <time>: n bytes` line and the file is truncated back; changed: the whole file moves to `attic/<file>.<unix nanos>` and an empty sealed file takes its place; a sealed file removed is named. Nothing is deleted (Law 4). World.CheckShelf runs Check over QueuePath, the ledger shelf and the value ledger — at Open (findings are Notes; the Claude Code hooks open the world per call) and after every act (loop.Engine.Seals, so the act fails naming the shelf, the attic and the queue tool). The classifier's Targets refusal stays the first line; the seal is the backstop for what it cannot read.
- The recall beat (hooks.go World.Recall): anchors from a shaped memory window (RecallOpts.Window) and toolbox @T lines, never a body; a stale index is rebuilt unless memory.long.rebuildOnStale is off — then one `degraded:` marker per recall, naming its hand-run door (memory.World.IndexCommand, `<dist> memory index`), replaces the raw drift echo.

- Births (births.go): every harness birth appends one line to `attic/births/<body>.jsonl` (logBirth; Births reads it, a torn line skipped) — {at, body, kind genesis|split|ascend|evolve-split|rebirth, from, by, doc}: relieve's young, mintAscended's ascendant, applyPlan's split young and rebirth, and EndGate on a pass for each genesis the gate exempted (Verdict.Born), only when the body has no line yet. bornAt is the first line's time, else — grandparented, a body born before the ledger — the author time of the commit that added its doc (git log --diff-filter=A), cached per body; AllSignals sets the `tenure` signal from it (value.TenureDays: whole days, zero when unknown).
- Trusted claims (claims.go): a write is judged by the claims the gate trusts (claimBase), never the raw README — Open and a harness mint (relief, ascension, evolution: reloadMinted) trust every claim; after that a claim a body added is trusted at once only when it takes no living owning body's soil (claimTakesLocked: a trusted claim or seat at, under or over it — open ground is a body's to claim); one that does is held (heldClaims): Policy and the gate judge the write by the trusted zone (trustedZone), the claimant's own gate fails the README that grants it and any write it alone admits, a reload never trusts it, and only a clean gate whose writer stands in the claimant's line above (parent, its line, the throne) carrying that README grants it (grantClaims).
