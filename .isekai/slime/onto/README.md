# slime-onto

- **Rank:** Slime
- **Territory:** `onto/`
- **Reports to:** orc-world
- **Minds:** slime-go-proving, slime-creature-docs
- **Purpose:** the ground truth of the ontology: the Turtle-subset schema and parser, the triple store, the forward-chaining reasoner, the shapes `onto check` enforces, the derivation of creatures and claims from their docs, the flow of facts along bonds, the @ONTO projection, and housekeep's chain law.

## Traits
- One prefix, `is:` = isekai:. schema.ttl declares the classes (Creature, Rimuru, Elf, Orc, Slime, Kijin, Mind, Doc, Fact with Law/Colony/Territory), the bonds (above transitive; truth, verdict, reports subPropertyOf above; wears/wornBy, owns, knows/knownBy, doc, shared) and four shapes: SlimeTruth (exactly one truth edge), SlimeTerritory (owns disjoint), MindWorn (≥ 1 wornBy unless shared), BondTarget (every above-target has a doc). The world's copy of the schema must equal onto.DefaultSchema (TestSchemaOnDiskMatchesBuiltIn).
- Overlap (validate.go `overlap`): two creatures asserting the same FILE is a lawful split, not a finding; the same DIRECTORY claimed twice collides, and so does a strict ancestor (src/auth vs src/auth/login). Two claims of one creature never collide with each other.
- derive() never writes: creature id = `<rank dir>-<folder lowercased>`; the doc is README.md, else `<folder>.md`, else SKILL.md, else the first .md; fields are read leniently from `- **Key:** value` lines (reports to / orc / elf / parent; territory / zone / owns; minds / mind / wears / hats), first wins, and a `## Territory` heading's backticked bullets count too. The parent falls back to the first creature of the expected rank the doc names, or rimuru.
- Claims: the structured Territory field is the authoritative claim list — a bare entry (a top-level dir, a file name) derives; a slashed entry derives only when rooted in the seat's own name (or `.isekai` / `src`), otherwise it is a cross-reference and mints nothing. Prose backticks derive owns only when they self-name the creature (selfNamesSpan) and are rooted in its seat or `.isekai`; a foreign file path, bare .isekai, anything under .isekai/tmp, URI templates, REST routes and a whole tree — a span that normalizes to one bare segment (`src/`) or carries a glob (`**/`) — never derive. Every owns edge records its provenance in DocRef.Claims (Claim{Lane structured|prose, Line}; ClaimOf reads it), and a SlimeTerritory finding names both claims' lanes and points at the line that made the claim.
- A retired seat (a `- **Retired:** true` line) keeps its name, bonds and Minds in the graph but derives no owns — neither its Territory field nor its prose — so the young of a split, an ascension or a relief never overlap it. It derives `is:retired true`; its `Heir` line derives `is:heir`, as does an ascendant's `Ascendant of` line (base → ascendant). HeirOf walks heir edges, through heirs that retired in turn, to the first live creature ("" when the line ends); Validate's HeirLive check (code, beside the shapes) finds a living creature whose one hop up is a retired seat with no live heir. OneHop is the one no-third-creature-between test, shared with world.
- Minds come from discover.SkillBases(WorldDir) — crafted-skills, base-skills, then the host dirs, first home wins; a skill whose name prefix is no rank dir is `shared`. A creature wears a mind its Minds field names or whose name appears as a whole word in its doc.
- Housekeep(root, heal, spawn): check-only reports and writes nothing; heal mints a missing creature home, rewires a missing chain edge, and rewires a dead bond (a `Reports to:` naming no live seat) to the rank's law parent — a live bond, law-shaped or not, stays the operator's. spawn seats draft homes for tracked top-level dirs nobody covers. Overlaps are reported, never rewritten. app runs heal at every world-touching CLI start and at init, so a heal must stay idempotent.
- CLI: `onto check` prints `@S PASS|FAIL n findings · creatures · minds · facts · triples` (non-zero on findings), plus show, project, owner (CLIOwner, when the binary wires it, answers with world.ZoneOfPath — the gate's own reading; else ownerOf's graph mirror: longest claim, authoring rank on a tie) and assert. Project(creature, budget) renders @ONTO by token budget (Tokens = runes/4, rounded up); Visible walks the bonds.
- cache.go: Stamp fingerprints what LoadLayout reads (ontology turtle, rank-dir docs, skill bases; path · size · mtime, dirs included); Cached memoizes LoadLayout on it — the TUI board and the web board's colony poll Cached (≈0.5 ms vs ≈13 ms a load on this repo). The cached World is shared and read-only; a writer (Record, the world) loads its own.
