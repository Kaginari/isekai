# slime-app

- **Rank:** Slime
- **Territory:** `app/`, `cmd/`
- **Reports to:** orc-app
- **Minds:** slime-go-proving, slime-wire-and-journals, slime-creature-docs
- **Purpose:** the ground truth of the engine's assembly — the CLI and its commands, init and founding, the session host (TUI, REPL, dash), the Courts host, the world tools, the Claude Code hooks, the container and selftest.

## Traits
- **cli** (`app/cli.go`): Main runs DockerAgent() first, then the command word (`command` finds it past leading flags), help/version, splitFlags + config.ParseFlags overrides (`--json`/`--format` → output.format), then healRunStart (a synchronous, fail-open onto housekeep heal) and New. init/config/memory/toolbox/onto/housekeep/guard/hook/install/ui/selftest return before a world opens; status, sessions and usage retry with NoWorld. The `commands` table is what `help` prints — a new command lands there.
- **assembly** (`app/app.go` New): config.LoadWith → Providers → the usage journal (`instruments/usage/<session>.jsonl`) → openWorld under the lexicon → the boot re-index of long memory → sandbox → gate → Shelf (`app/shelf.go`: shelfOrder bash … ask, then worldToolNames dispatch recall remember toolbox onto skill desk plan pulse) → MCP → Discover → hooks, MissingPolicy, the drainer, the SessionStore, the Court. Every problem met on the way is a hole (`@?`), never a silent skip.
- **evolution** (`app/evolve.go`): New arms law.evolution after the sandbox (evolutionOptions from config, the survey — readSurvey cached 30s, one unit per territory through slimePlan — the gate's sandbox and verifyTimeout, the `evolved` sink); the run-start sweep runs for run/resume/goal/handoff/review/found, at REPL start, and in the TUI before the program (its events held, then sent); `evolved` sends tui.EvEvolution to the TUI host (fanned to the web bus as an `evolution` event) or the web bus, else prints `✦ …` on stderr; `isekai evolve list|show|apply|reject` and status's evolution block read the world's queue and value rows.
- **init** (`app/cli.go` cmdInit, `app/found.go`, `app/init_render.go`, `app/setup.go`, `app/freeport.go`): levels light|medium|complex; complex continues as the `found` session with law.gate.rightAuthor forced off. The wire form cmdInit prints is byte-stable (pipes, bench, tests); renderInit draws the styled face only when styledInit says the output is a colour terminal. The first-run Huh form writes the world's config.yaml with a free board port from 8092–8199 (never 4000, 7411, 8080, 8081, 8090).
- **session host** (`app/tui.go`, `app/tuiboard.go`, `app/repl.go`, `app/web.go`, `app/dash.go`, `app/board.go`, `app/watchdog.go`): tuiHost implements tui.Host; wantsTUI needs a TTY on both ends, not TERM=dumb, no --plain or <PREFIX>PLAIN. Events fan out to the terminal and the webBus (board.Live, replay ring webReplay 4000); a choice answered on the dash and the terminal resolves once, never blocking. Plans() re-reads decks only when plansSig moves (deck files live and archived, offices, session birth). builtinCommands is the slash menu.
- **the look** (`app/theme.go`, `app/tuivalue.go`): setTheme is the one switch for every surface — theme.Check, ui.theme and ui.mode patched into the local layer's file, the config reloaded, a session override kept when a higher layer (env, --set) pins it, then EvTheme through the host (terminal and web bus) or straight onto the web bus; the board's Theme/SetTheme and tuiHost.SetTheme both reach it, and /theme in the repl or the dashboard's ask too. footerValue fills the terminal's FooterView from valueView (≤ 1 fold a second): cfg.Meters, the races, each body's meter, the throne's score, nearestAscension.
- **courts and world tools** (`app/court.go`, `app/worldtools.go`, `app/forge.go`, `app/lessons.go`): the Court tracks every body; Finish lifts a report's `@$` orders into the order book, drained as dispatches at the turn boundary and re-checked by the chain gate. The plan deck is one JSON per body under <world>/tmp/plans (config override via planDir); stale decks move to `archive/` at boot, never deleted. `/forge` and `isekai forge list|show|mint|reject` are the forge's desk: open drafts by hash (world.ReadForgeLedger), a skill mint writes <world>/crafted-skills/<name>/SKILL.md (never an overwrite; --version keeps v(n) under versions/; a name another home wears is refused), a tool mint patches tools.custom at the classifier's class (tool.SplitArgv, InterpreterEval refused unless --force, outward/destructive only on --yes or the TTY's y, crafted provenance); the remember tool refuses world.ForgeTags; Discover reads skills through discover.SkillBases and keeps two-homes holes in Found.Holes (status prints them); `lessons` ranks the guts' readings over a journal or bench job dir.
- **Claude Code** (`app/claude.go`): `hook session-start|prompt|pre-tool|post-tool|stop` never calls a model and is silent outside a world; pre-tool only tightens Claude Code's permission; stop runs the gate (dutiesDone and rightAuthor off) and never trusts a verify line added this turn. `install --claude [--global] [--yes]` merges the ccEvents hooks into `.claude/settings.local.json` (or `~/.claude/settings.json`), shows the change, writes only with --yes, Stop timeout 600.
- **container** (`app/container.go`): docker run with the world read-write at its own path, the binary and hostReadOnly paths read-only, the session store read-write, HOME a tmpfs, the caller's uid; passEnv forwards by NAME only (terminal vars, <PREFIX>*, *_API_KEY, *_BASE_URL); inside, the <PREFIX>DOCKER_AGENT marker makes the flag a no-op. The runtime image is embedded and tagged by its hash (DefaultRuntimeImage).
- **guards and hooks** (`app/guard*.go`, `app/hooks.go`, `app/permissions.go`, `app/onto_hook.go`): the sed guard refuses anchored in-place sed edits through bash (use edit); the tmp guard rewrites absolute tmp paths into the body's scratch; config shell hooks run with `sh -c`, JSON on stdin, 10 s default, exit 2 blocks, `@S` stdout is wire — outside the sandbox, as trusted config.
- **selftest and law** (`app/selftest.go`, `app/embed.go`): `selftest` answers one `@S PASS n checks` from core and app checks in a throwaway world; app/law/isekai.md is the embedded law Init writes, kept equal to the world's own copy by test.
